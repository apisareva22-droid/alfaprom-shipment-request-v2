# АЛЬФАПРОМ — заявка на отгрузку

Онлайн-форма для заполнения заявки покупателем и формирования готового документа.

## Возможности

- пошаговое заполнение для юридического лица, ИП или физического лица;
- подстановка реквизитов организации после ввода ИНН;
- получение через транспортную компанию или самовывоз;
- выбор терминала либо адресной доставки;
- ввод паспортных данных получателя с форматированием номера;
- формирование двухстраничного документа для печати и сохранения в PDF;
- выбор удобного способа подписания: печать, ЭДО или последующая отправка.

## Обновление после проверки QA

- Семь шагов: покупатель, реквизиты, доставка, получатель и основание, документы, подписание, проверка.
- Общие проверки ИНН, телефонов, email и документов на клиенте и сервере.
- Другой грузополучатель имеет собственный ИНН или паспорт; комментарий включён в PDF.
- PDF формируется в изолированном документе. Библиотеки закреплены локально в `vendor/`; внешний CDN не требуется.
- При изменении данных прежний PDF и вложения сбрасываются.
- Черновик хранится только в `sessionStorage` текущей вкладки, не более 24 часов; файлы не сохраняются.
- Заявка считается принятой только после серверного подтверждения с номером. Повтор той же отправки не создаёт дубль; сбой Telegram не отменяет сохранение.
- СБИС не предлагается как подключённая функция. Для ЭДО файл передаётся бухгалтерии; отдельная кнопка сообщает менеджеру о подготовленной заявке.

## Проверки

```sh
npm ci
npm run check
npm test
python -m http.server 8765 --bind 127.0.0.1
```

Проверки охватывают валидацию, разные реквизиты получателя, HTML-экранирование, сброс старого документа и терминала, тайм-ауты, серверное подтверждение, ограничения вложений и повтор после сбоя хранилища/уведомления.

После редактирования `validation.js` выполните `node scripts/sync-validation.cjs`: одинаковые правила должны попасть в `apps-script/Code.gs`.

Сначала обновите существующее развертывание Apps Script, затем сайт. Старый сервер не поддерживает протокол подтверждения 2: новая форма остановит отправку до обновления.

## Данные

Форма запрашивает только сведения, необходимые для подготовки заявки. Если реквизиты не найдены, поля остаются доступными для ручного заполнения.

## Запуск

Сайт опубликован через GitHub Pages. Для локального просмотра достаточно открыть `index.html` в браузере.
